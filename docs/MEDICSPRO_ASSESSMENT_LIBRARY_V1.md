# Biblioteca MedicsPro de Anamneses V1

Origem: curadoria do MedicsPro histórico (`0fd709612598fa93a9cf0517b9ba924b1405ec83`), absorvida pela Assessment Engine canônica.

V1 publica apenas **Anamnese Médica Geral** e **Anamnese Psiquiátrica** como `platform-owned`, com versão publicada imutável. Especialidade é metadado de relevância/ranking; não concede ACL. Templates de clínica continuam no mesmo engine e não são alterados.

O conteúdo usa click-first, prose-when-needed: escolha única, múltipla escolha, sim/não e escala quando seguros; narrativa para história, síntese, exame mental e risco contextual. Medicamentos e alergias são snapshots contextuais, não substitutos da fonte canônica de prescrições/cadastro clínico. PHQ-9/GAD-7 permanecem Instrumentos Clínicos/Nexus.

Não há lógica condicional nesta V1 porque o engine atual não a suporta. Backlog histórico catalogado: Ginecologia, Dermatologia, Pediatria, Cardiologia, Ortopedia e Oftalmologia.

O inventário histórico reportado contém 181 **itens de formulário** (perguntas, opções, agrupamentos e elementos auxiliares), não 181 perguntas. Antes da próxima especialidade, o arquivo-fonte histórico deve ser preservado junto do inventário detalhado para contagem auditável.
