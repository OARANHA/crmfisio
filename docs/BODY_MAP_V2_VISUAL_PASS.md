# Body Map V2 — visual pass

Screenshot review findings:

- anatomical canvas works, but region abbreviations compete with the body drawing;
- the large “Regiões rápidas” block creates visual noise and duplicates the canvas interaction;
- selection should communicate the full anatomical name without forcing the user to decode codes;
- the form should stay focused on one clinical finding at a time.

Visual pass goals:

1. keep front/back figures side by side;
2. remove the large quick-region cloud;
3. add a compact region selector as an alternate accessible path;
4. use smaller anatomical hotspots with full-name hover/focus labels;
5. make the body illustration more readable while keeping the existing structured persistence;
6. preserve free-point mode and all assessment_body_points compatibility.
