# Design System V2.1 — legibilidade e hierarquia

## Objetivo
Refinar o MedicsPro para uma linguagem visual clínica, contemporânea e calma, sem neon, grade decorativa ou estética de dashboard futurista.

## Ajustes desta passagem
- contraste correto de botões primários no tema claro;
- escala tipográfica operacional mais confortável;
- superfícies claras com hierarquia mais nítida;
- cards com elevação discreta e menos aparência de formulário legado;
- controles com maior área de clique e melhor leitura;
- navegação com tipografia e ícones mais presentes;
- canvas desktop ligeiramente mais amplo e melhor uso de espaço.

## Princípios
1. Informação clínica vem antes da decoração.
2. Espaçamento cria hierarquia antes de bordas.
3. Monospace somente para códigos, horários, IDs e dados técnicos.
4. Ações primárias precisam ter contraste adequado nos dois temas.
5. Dark e light devem parecer o mesmo produto, não dois skins diferentes.
